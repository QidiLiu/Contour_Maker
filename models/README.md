# models/

Committed artifacts for the **ultrasound** comparison. They are the only
training outputs that are checked in (the full `runs/` directory is gitignored).

| File | Scheme | Input | Outputs |
|---|---|---|---|
| `yolo26n_seg.mnn` | YOLO-Seg | (1,3,512,512) | `output0` (1,300,38), `output1` (1,32,128,128) |
| `yolo26n_det.mnn` | Det-UNet stage 1 | (1,3,512,512) | `output0` (1,300,6) |
| `mkunet.mnn` | Det-UNet stage 2 | (1,1,256,256) | `logits` (1,1,256,256) |
| `rfdetr_seg_nano.mnn` | RF-DETR-Seg | (1,3,384,384) | `dets` (1,100,4), `labels` (1,100,5), `masks` (1,100,96,96) |

`.onnx` files are generated by the `export_onnx.py` scripts and are gitignored.
ADE20K models are exported into `models/ade20k/` and are also gitignored; run the
export commands in `docs/reproduce.md` to regenerate them.

Conversion:

```bash
MC=build/mnn-conv/MNNConvert
$MC -f ONNX --modelFile models/yolo26n_seg.onnx --MNNModel models/yolo26n_seg.mnn
```

See [`../docs/deployment.md`](../docs/deployment.md) for the full tensor contract.
